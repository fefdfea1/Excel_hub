# 엑셀 템플릿

무료 엑셀 템플릿을 소개하고 배포하는 사이트입니다.
Next.js로 만들었고, 빌드하면 정적 파일만 나오기 때문에 어떤 웹 호스팅에든 그대로 올릴 수 있습니다.

**핵심: 템플릿 하나 = 폴더 하나.** 폴더를 넣으면 사이트에 나타나고, 폴더를 지우면 사라집니다.
목록에 등록하는 절차나 고쳐야 할 코드가 없습니다.

---

## 1. 시작하기

Node.js 20 이상이 필요합니다. ([nodejs.org](https://nodejs.org) 에서 LTS 버전을 받으세요.)

```bash
npm install       # 처음 한 번만
npm run dev       # 개발 서버 → http://localhost:3000
```

파일을 저장하면 브라우저가 알아서 새로고침됩니다.

---

## 2. 폴더 구조

```
.
├─ app/                        페이지
│  ├─ layout.tsx               모든 페이지를 감싸는 껍데기 (헤더·푸터·글꼴)
│  ├─ page.tsx                 목록 페이지  (/)
│  ├─ not-found.tsx            404 페이지
│  ├─ sitemap.ts               /sitemap.xml 을 만듭니다 (템플릿 목록 자동 반영)
│  ├─ robots.ts                /robots.txt 를 만듭니다
│  ├─ icon.svg                 브라우저 탭 아이콘
│  ├─ globals.css              색·여백 등 디자인 토큰
│  ├─ fonts/                   본문 글꼴 (Pretendard)
│  └─ t/[slug]/page.tsx        템플릿 상세 페이지  (/t/inventory/)
│
├─ components/                 화면 조각
│  ├─ Header.tsx               위쪽 바
│  ├─ Footer.tsx               아래쪽 바 + 댓글 영역
│  ├─ Comments.tsx             Disqus 댓글
│  ├─ TemplateCard.tsx         목록의 카드 한 장
│  ├─ SheetViewer.tsx          상세 페이지의 시트 넘겨보기
│  ├─ JsonLd.tsx               검색 엔진용 구조화 데이터 (화면에는 안 보임)
│  └─ Container.tsx            가운데 정렬용 껍데기
│
├─ lib/
│  └─ templates.ts             public/templates 폴더를 읽어 템플릿 목록을 만듭니다
│
├─ scripts/
│  ├─ build-previews.mjs       엑셀 → 미리보기 이미지 자동 생성
│  ├─ render.mjs               시트를 그리는 코드
│  ├─ cached.mjs               엑셀에 저장된 수식 계산 결과 읽기
│  └─ build-og.mjs             공유 카드 이미지(og.png) 생성
│
├─ public/
│  ├─ og.png                            공유 카드 이미지 (npm run og 로 생성)
│  └─ templates/                        ★ 콘텐츠는 전부 여기 있습니다
│     └─ 07_재고관리_입출고_안전재고/      폴더 하나가 템플릿 하나 (폴더 이름 = 제목)
│        ├─ meta.json                   설명·태그·표지·사용 순서
│        ├─ 재고관리_입출고_안전재고_월간재고.xlsx   다운로드될 파일
│        └─ previews/
│           ├─ 01-사용안내.png
│           ├─ 02-품목마스터.png
│           └─ ...
│
├─ site.config.ts              ★ 사이트 이름·댓글 설정 등 (자주 고치는 곳)
├─ next.config.mjs             빌드 설정
└─ package.json
```

**자주 건드리는 곳은 두 군데뿐입니다.**
콘텐츠는 `public/templates/`, 사이트 전체 설정은 `site.config.ts`.

## 3. 템플릿 추가하기

### 3-1. 폴더 만들기

`public/templates/` 안에 `숫자_이름` 형태로 폴더를 만듭니다.
**원본 엑셀 폴더와 같은 이름을 쓰면 됩니다.**

```
public/templates/10_급여대장_4대보험_자동계산/
```

- **앞 숫자**는 목록 순서입니다. 기본은 작은 번호부터(01, 02, 03 …) 보여줍니다.
  기존 템플릿이 01 ~ 09 이므로 새 것은 10 으로 하면 맨 아래에 붙습니다.
  중간에 끼우고 싶으면 앞뒤 폴더의 번호를 다시 매기거나, `meta.json` 의 `order` 로 지정하세요.
  순서를 뒤집으려면 `site.config.ts` 의 `listOrder` 를 `'desc'` 로 바꿉니다.
- **숫자 뒤 이름이 그대로 제목이 됩니다.** 밑줄은 띄어쓰기로 바뀝니다.
  → `10_급여대장_4대보험_자동계산` → 제목 "급여대장 4대보험 자동계산"
  폴더 이름을 바꾸면 제목도 같이 바뀝니다.

### 3-2. 엑셀 파일 넣기

폴더 안에 `.xlsx` 파일을 그냥 넣습니다.

```
public/templates/10_급여대장_4대보험_자동계산/급여대장_4대보험.xlsx
```

폴더 안의 엑셀 파일을 자동으로 찾아서 다운로드 버튼에 연결합니다.
**파일 이름이 곧 사용자가 받게 될 이름**이므로, 알아보기 쉬운 이름으로 지어주세요.

### 3-3. meta.json 쓰기

같은 폴더에 `meta.json` 을 만듭니다.

```json
{
  "slug": "payroll",
  "desc": "사원 정보를 한 번 등록하면 매달 급여와 4대보험 공제액이 자동으로 계산됩니다.",
  "tags": ["급여", "노무"],
  "cover": "급여대장",
  "steps": [
    ["사원명부", "사번·이름·입사일·기본급을 등록합니다."],
    ["급여입력", "그 달의 근무일수와 수당만 넣으면 됩니다."],
    ["급여대장", "자동으로 계산된 지급액과 공제액이 나옵니다."]
  ]
}
```

| 항목 | 설명 | 생략하면 |
|---|---|---|
| `slug` | 주소에 쓰는 영문 이름 → `/t/payroll/` | 폴더 이름(한글 주소가 됩니다) |
| `desc` | 한두 줄 설명 | 설명 없이 표시 |
| `tags` | 카드에 붙는 꼬리표 | 꼬리표 없음 |
| `cover` | 카드 썸네일로 쓸 시트. **시트 이름**을 쓰거나 몇 번째인지 숫자로 | 첫 번째 이미지 |
| `steps` | `["제목", "설명"]` 쌍의 목록. 상세의 '사용 순서' | 그 영역이 안 나옴 |
| `title` | 제목을 직접 지정 (예: 가운뎃점으로 꾸미고 싶을 때) | **폴더 이름** |
| `order` | 정렬값을 직접 지정 | 폴더 이름 앞 숫자 |
| `draft` | `true` 면 사이트에서 감춥니다 | 보임 |

> `slug` 를 생략하면 주소에 한글이 그대로 들어갑니다. 동작은 하지만 링크를 복사했을 때
> `%EA%B8%89%EC%97%AC…` 처럼 길어지므로, 짧은 영문 이름을 적어두는 편이 좋습니다.

> `draft: true` 는 준비 중인 템플릿을 잠시 내려둘 때 유용합니다. 폴더를 지울 필요가 없습니다.

### 3-4. 미리보기 이미지 만들기

```bash
npm run previews
```

엑셀을 열어 **시트마다 이미지를 한 장씩** 그려서 `previews/` 폴더에 넣어줍니다.
파일 이름은 `01-사용안내.png` 처럼 `순서-시트이름` 이 됩니다.

```bash
npm run previews                      미리보기가 없는 템플릿만
npm run previews -- --force           전부 다시 만들기
npm run previews -- 07_재고관리_입출고_안전재고        그 폴더만
npm run previews -- --force 07_재고관리_입출고_안전재고
```

엑셀을 고친 뒤에는 `--force` 로 다시 만들면 미리보기도 최신이 됩니다.

### 3-5. 확인하기

```bash
npm run dev
```

끝입니다. 어디에도 등록할 필요가 없습니다.

## 4. 이미지 다루기

`previews/` 폴더의 이미지 파일이 곧 상세 페이지의 시트 목록입니다.

- **순서를 바꾸려면** → 파일 이름 앞 숫자를 바꾸세요. (`01-`, `02-` …)
- **시트 이름을 바꾸려면** → 숫자 뒤 이름을 바꾸세요. 화면의 탭 이름이 그대로 바뀝니다.
- **빼려면** → 파일을 지우세요.
- **직접 찍은 스크린샷을 넣으려면** → 같은 규칙으로 이름만 맞춰 넣으면 됩니다.
  `.png` `.jpg` `.webp` `.avif` `.gif` `.svg` 를 쓸 수 있습니다.

### 썸네일만 따로 지정하기

카드에 시트 이미지 말고 **따로 만든 썸네일**을 쓰고 싶다면,
파일 이름을 `cover` 로 시작하게 만들어 넣으세요.

```
public/templates/07_재고관리_입출고_안전재고/cover.png          ← 이게 최우선으로 쓰입니다
public/templates/07_재고관리_입출고_안전재고/previews/cover.jpg ← 여기 넣어도 됩니다
```

`cover` 로 시작하는 이미지는 시트 목록에는 나오지 않고 썸네일로만 쓰입니다.
없으면 `meta.json` 의 `cover` 값을, 그것도 없으면 첫 번째 이미지를 씁니다.

권장 크기는 **1200 × 750** (16:10) 입니다. 다른 비율이면 잘려 보일 수 있습니다.

### 자동 생성되는 미리보기의 규칙

`npm run previews` 가 그리는 그림은 엑셀을 그대로 찍은 사진이 아니라 다시 그린 것입니다.
보기 좋게 만들기 위해 아래 규칙을 씁니다.

- **표가 그림을 채우도록 가로·세로를 각각 맞춥니다.** 열이 많으면 글자가 작아지고,
  행이 몇 줄뿐이면 행이 두꺼워집니다. 남는 공간은 위아래·좌우로 똑같이 나눠 가운데에 둡니다.
- **글자는 칸 크기에 맞춰 같이 줄어듭니다.** 그래서 머리글이 `기사명(...` 처럼 잘리지 않습니다.
- **값이 없어도 테두리가 있는 칸은 표의 일부로 그립니다.** 입력용 빈 칸을 건너뛰면
  수식이 든 열에만 테두리가 남아 표가 세로 줄무늬처럼 깨져 보입니다.
- **표 오른쪽의 수식 작업용 열은 빼고 그립니다.** 테두리도 배경색도 없는 열이 대상입니다.
  (예: 품목검색 시트의 `일치(자동)` `검색키(자동)` 열. 그대로 두면 `FALSE` 가 줄줄이 나옵니다.)
  `←` `※` 로 시작하는 안내 문구나 제목 글자가 든 열은 남깁니다.
- **옆 칸에 막혀 잘릴 글자는 그 열을 넓혀서** 끝까지 보여줍니다.
  (예: 사용안내 시트의 `④ 차량별집계 / 업체별미수금 / 기사수당내역`)
- 그래도 안 들어가면 **글자를 조금 줄여서** 보여줍니다. 말줄임표는 마지막 수단입니다.
- **칸은 아주 넓은데 값이 짧으면 값을 왼쪽(라벨 쪽)으로 당깁니다.**
  엑셀은 숫자를 오른쪽 끝에 붙이는데, 설정 입력칸처럼 한 칸이 넓으면
  라벨과 화면 반 폭만큼 떨어져 깨진 것처럼 보이기 때문입니다.
- 최대 **30행 26열**까지 그립니다. 미리보기이므로 그 뒤는 생략합니다.

작업용 열까지 보여주고 싶다면 엑셀에서 그 열에 테두리나 배경색을 주면 됩니다.
반대로 특정 시트를 원하는 모습으로 보여주고 싶다면, 직접 찍은 스크린샷을 같은 이름으로
`previews/` 에 넣으면 됩니다. `--force` 를 쓰지 않는 한 덮어쓰지 않습니다.

## 5. 템플릿 수정 · 삭제

| 하고 싶은 것 | 하는 방법 |
|---|---|
| 제목 바꾸기 | **폴더 이름**을 바꿉니다 (또는 `meta.json` 에 `title` 지정) |
| 설명·태그 바꾸기 | `meta.json` 을 고칩니다 |
| 엑셀 파일 교체 | 폴더의 `.xlsx` 를 새 것으로 바꾸고 `npm run previews -- --force <폴더이름>` |
| 순서 바꾸기 | 폴더 이름 앞 숫자를 바꿉니다 |
| 목록 전체 순서 뒤집기 | `site.config.ts` 의 `listOrder` 를 `asc` ↔ `desc` |
| 잠시 감추기 | `meta.json` 에 `"draft": true` 를 넣습니다 |
| 완전히 삭제 | 폴더를 통째로 지웁니다 |

## 6. 사이트 설정

`site.config.ts` 한 파일에 모여 있습니다.

| 값 | 설명 |
|---|---|
| `name` | 브라우저 탭과 헤더에 나오는 이름 |
| `headline` / `tagline` | 목록 페이지 맨 위 문구 |
| `titleDefault` | 검색 결과 첫 줄에 나오는 제목 (30자 안팎) |
| `description` | 검색 결과·공유 카드 설명 |
| `keywords` | 검색 엔진에 주는 낱말 힌트. 열 개 안쪽으로 |
| `ogImage` | 카카오톡·페이스북에 뜨는 이미지 경로 |
| `url` | **배포한 실제 주소.** 공유 카드가 제대로 나오려면 꼭 바꿔주세요 |
| `colophon` | 맨 아래 한 줄 |
| `autoplaySeconds` | 상세 페이지 미리보기 자동 넘김 간격(초). `0` 이면 끔 |
| `listOrder` | 목록 정렬. `asc` 작은 번호부터 / `desc` 큰 번호부터 |

색이나 여백은 `app/globals.css` 위쪽의 `:root` 값만 고치면 사이트 전체에 반영됩니다.

## 7. 댓글 (Disqus)

사이트 하단에 댓글창이 하나 있고, **모든 페이지가 이 스레드 하나를 같이 씁니다.**
목록에서 보든 상세에서 보든 같은 댓글이 보입니다.

설정은 `site.config.ts` 의 `comments` 항목입니다.

| 값 | 설명 |
|---|---|
| `shortname` | disqus.com 에서 사이트를 등록하면 받는 고유 이름. 비워두면 안내 문구만 나옵니다 |
| `identifier` | 스레드 식별자. **한 번 정하면 바꾸지 마세요.** 바꾸면 기존 댓글이 사라진 것처럼 보입니다 |
| `heading` / `hint` | 댓글 영역 제목과 안내 문구. 기본값은 문제점·개선사항과 **템플릿 추가요청**을 함께 받습니다 |

### 처음 설정할 때

1. [disqus.com](https://disqus.com) 에서 **I want to install Disqus on my site** 를 고릅니다.
2. 만들어진 **Shortname** 을 `site.config.ts` 의 `comments.shortname` 에 넣습니다.
3. `site.config.ts` 의 **`url` 을 실제 배포 주소로** 바꿉니다. (아래 설명 참고)
4. 배포한 뒤 Disqus 관리자의 **Settings → Trust this domain** 에 그 도메인을 등록합니다.

### `url` 이 중요한 이유

Disqus는 스레드를 만들 때 넘겨받은 주소에 **실제로 접속해서 확인**합니다.
그래서 이 사이트는 현재 브라우저 주소가 아니라 `site.config.ts` 의 `url` 을 **고정으로** 넘깁니다.

- 이렇게 해야 localhost, 미리보기 배포, `www` 있는 주소·없는 주소 어디서 접속하든
  **댓글이 하나의 스레드로 모입니다.**
- `url` 이 기본값(`https://example.com`)인 동안에는 댓글을 아예 불러오지 않고 안내 문구만 보여줍니다.
  잘못된 주소로 스레드가 만들어지는 것을 막기 위해서입니다.

> 댓글은 화면을 아래로 내려 댓글 영역이 보일 때 불러옵니다. 첫 화면 로딩이 느려지지 않습니다.
> 광고 차단 확장 프로그램이 Disqus를 막는 경우가 있는데, 이때는 안내 문구가 대신 나옵니다.

## 8. 배포

```bash
npm run build
```

`out/` 폴더에 정적 파일이 만들어집니다. **이 폴더의 내용을 그대로 올리면 됩니다.**

| 호스팅 | 설정 |
|---|---|
| Vercel | 저장소를 연결하면 자동으로 인식합니다 |
| Netlify | Build command `npm run build`, Publish directory `out` |
| Cloudflare Pages | 위와 동일 |
| GitHub Pages | `out/` 폴더 내용을 `gh-pages` 브랜치에 올립니다 |
| 일반 웹호스팅 | `out/` 안의 파일을 FTP로 올립니다 |

배포 전에 `site.config.ts` 의 `url` 을 실제 주소로 바꿔주세요.

로컬에서 빌드 결과를 확인하려면:

```bash
npm run build
npx serve out
```

## 9. 검색 노출 (SEO)

건드릴 것 없이 빌드하면 아래가 자동으로 만들어집니다.

| 만들어지는 것 | 하는 일 |
|---|---|
| `/sitemap.xml` | 목록과 템플릿 페이지 주소를 검색 엔진에 한 번에 알려줍니다. 템플릿을 넣고 빼면 자동으로 따라옵니다 |
| `/robots.txt` | 모든 검색 로봇을 허용하고 사이트맵 위치를 알려줍니다 |
| 페이지별 제목·설명 | 상세 페이지 제목은 "재고관리 입출고 안전재고 엑셀 양식 무료 다운로드" 처럼 만들어집니다. 설명은 `meta.json` 의 `desc` 를 씁니다 |
| 대표 주소(canonical) | 같은 내용이 여러 주소로 잡히는 것을 막습니다 |
| 공유 카드 | 카카오톡·페이스북에 붙였을 때 제목·설명·이미지가 나옵니다 |
| 구조화 데이터 | "무료로 받을 수 있는 엑셀 서식"이라는 것과 목록 → 템플릿 경로를 기계가 읽는 형식으로 넘깁니다 |

**검색에 잘 나오게 하려면 이것만 해주세요.**

1. `site.config.ts` 의 `url` 이 실제 배포 주소인지 확인합니다. 이 주소가 모든 검색 정보의 기준이 됩니다.
2. [구글 서치 콘솔](https://search.google.com/search-console) 과
   [네이버 서치어드바이저](https://searchadvisor.naver.com) 에 사이트를 등록하고,
   사이트맵 주소(`주소/sitemap.xml`)를 한 번 제출합니다.
3. 소유 확인용 코드를 받으면 `app/layout.tsx` 의 `metadata` 에 아래처럼 넣습니다.

   ```ts
   verification: {
     google: '구글에서 받은 코드',
     other: { 'naver-site-verification': '네이버에서 받은 코드' },
   },
   ```

**검색 결과에 잘 걸리는 `meta.json` 쓰는 법**

- `desc` 는 그 서식으로 무엇을 하는지 한두 문장으로 씁니다. 이 문장이 검색 결과의 설명으로 그대로 나갑니다.
- `tags` 에는 사람들이 실제로 검색할 만한 말을 넣습니다. (`재고`, `제조`, `건설` 처럼)
- 폴더 이름이 곧 제목이므로, 폴더 이름에 찾기 쉬운 말을 넣는 것이 가장 효과가 큽니다.

사이트 이름이나 템플릿 개수를 바꾼 뒤에는 공유 카드 이미지를 다시 만들어 주세요.

```bash
npm run og        # public/og.png 를 다시 그립니다
```

직접 그린 1200×630 이미지를 `public/og.png` 에 덮어써도 됩니다.

## 10. 자주 겪는 문제

**미리보기 이미지가 안 나와요**
`npm run previews` 를 실행했는지 확인하세요. 이미 이미지가 있으면 건너뛰므로,
다시 만들려면 `--force` 를 붙여야 합니다.

**미리보기의 숫자가 비어 있어요**
엑셀에 계산 결과가 저장되어 있지 않은 경우입니다.
엑셀에서 파일을 열어 한 번 저장한 뒤 다시 `npm run previews -- --force` 를 실행하세요.

**미리보기에 FALSE 나 TRUE 가 줄줄이 나와요**
엑셀에 숨기지 않은 수식 작업용 열이 있는 경우입니다. 보통은 자동으로 걸러지지만,
그 열에 테두리나 배경색이 들어가 있으면 표의 일부로 보고 그립니다.
엑셀에서 해당 열의 서식을 지우거나 열을 숨긴 뒤 `npm run previews -- --force <폴더이름>` 을 다시 실행하세요.

**미리보기 글자가 깨져요**
한글 글꼴을 못 찾은 경우입니다. Windows·macOS에서는 기본 글꼴을 자동으로 씁니다.
리눅스에서는 `sudo apt install fonts-nanum` 으로 설치한 뒤 다시 실행하세요.

**댓글이 안 보여요**
`site.config.ts` 의 `shortname` 과 `url` 이 맞는지, Disqus 관리자에 도메인이 등록되어 있는지 확인하세요.

**"The thread you are attempting to post on is closed" 가 떠요**
Disqus가 확인할 수 없는 주소(localhost 등)로 스레드가 만들어지면 닫힌 상태가 됩니다.
`site.config.ts` 의 `url` 을 실제 배포 주소로 바꾸면 해결됩니다.
이미 닫힌 스레드가 만들어졌다면 Disqus 관리자의 **Moderation → Threads** 에서 해당 스레드를
찾아 열어주거나 삭제하세요. 아직 댓글이 없다면 `comments.identifier` 값을 한 번 바꾸는 것이 가장 간단합니다.

**다운로드 버튼이 안 나와요**
템플릿 폴더 안에 `.xlsx` 파일이 있는지 확인하세요. 파일이 없으면 버튼이 숨겨집니다.
